About this website

This website is currently under construction. Several information and images remains missing. This website replaces the old portfolio experience for improved screen responsiveness and a more touch-friendly experience.

This website is heavily influenced by Windows 8.1 Metro UI but is not affiliated by Microsoft (C). The design choice was intended to emphasize my experience in .NET Core despite the fact that this website itself does not use .NET by any means since it runs on Jekyll and GitHub Pages.
